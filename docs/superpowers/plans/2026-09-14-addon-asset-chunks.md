# Bounded Asset Chunk Primitive Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for this single reviewed increment; the two parts below are delivered as one coherent frame/assembly package. No commits, staging, resets, worktrees or changes to other agents' work. Root owns execution, review and build.

**Goal:** Deliver dedicated bounded asset DTOs and a host-only prepaid assembly-to-decoder primitive, with executable lifetime evidence. This slice does not make SDK asset transfers operational.

**Architecture:** Reuse Foundation's C6 closed-field Codable pattern and the existing ImageIO decoder. One non-actor, lock-gated assembler belongs to one admitted runtime incarnation; it has one transfer slot and no worker queue, timer or task of its own. Finish returns only an already protected `AssetRasterBacking`, never assembled `Data`.

**Tech Stack:** Swift 6, Foundation, Swift Testing, existing CascadeContracts/CascadeRuntime/ImageIO implementation.

**Spec:** Read `docs/superpowers/plans/2026-09-13-addon-asset-transfer-decision.md` and `.scratch/cascade-product/issues/21-asset-transfer.md` first. Approved: 65,536-byte chunks, 1,048,576 compressed bytes, 1,000,000 pixels, unchanged 524,288-byte total ordinary envelope limit. No disk staging, native launcher or C0d changes. Preserve reviewed source bytes outside the explicitly named modification scope.

## Task 1 — Dedicated bounded frame contract

- [x] Define `AssetTransferOperation: String, Codable, Sendable` with `begin`, `chunk`, `finish`, `abort`; public `AssetTransferRequest` and `AssetTransferResponse` conform to Codable/Equatable/Sendable. Constructors and direct decoder both enforce schema 1 and exact operation/result fields, matching C6.
- [x] Request common fields: `schemaVersion: Int`, `requestID: UUID`, `operation`. Begin adds `publicationID: PublicationID`, `totalBytes: Int`; chunk adds `transferID: UUID`, `offset: Int`, `bytes: Data`; finish/abort add only `transferID`. No payload owner, path, partition, digest or deadline. Begin accepts 1...1,048,576; chunk accepts offset 0..<1,048,576 and 1...65,536 raw bytes with checked end <=1,048,576. Stateful exact remaining/order is the assembler's responsibility.
- [x] Response common fields: schemaVersion/requestID/operation/result. Results: `begun` (begin only, transferID); `acknowledged` (chunk/abort, transferID and nextOffset for chunk only); `imported` (finish only, transferID and existing AssetHandle); `failure` (any operation, failureCode and nonempty failureReason <=4,096 UTF-8 bytes). Exact request UUID/operation and existing token must match in `validate(matching:)`; begin's successful token is host minted. A request UUID is correlation, never authority or retransmission support.
- [x] `AssetTransferFrameProfile.v1` identifies implemented syntax only; it does not claim negotiation. Codec offers the same four typed encode/decode APIs as StorageFrameCodec, accepts optional profile, rejects nil before parsing, and enforces `maximumEncodedBytes = 196_608` before decoding. Do not map a runtime protocol version or extend generic service payload limits.
- [x] Record exact output field byte accounting. A 65,536-byte chunk has 87,384 base64 characters; worst slash escaping is 174,768 bytes. The fixed chunk keys, two UUIDs, operation, schema, commas/braces/quotes and bounded numeric values fit within 512 additional bytes: <=175,280, below 196,608. Failure reason worst JSON escaping is 24,576 plus fixed fields <=512. Begin PublicationID and imported AssetHandle use their existing validated field bounds and must receive separate concrete arithmetic in code comments/tests. Enclosing adapter still owes the 524,288-byte complete-envelope proof; no wrapper is implemented here.
- [x] Run focused behavioral coverage (initial governor RED and separate assembler sensitivity mutants are distinguished in the verification report): every operation/result round trip; exact field sets; forbidden/missing/null fields; unknown schema/discriminants; direct Codable semantics; multibyte reason byte bound; 65,536-byte all-0xff worst escaping; 65,537 rejection; begin 0/1/1,048,576/1,048,577; Int extremes and overflow-safe offset; nil profile precedes malformed JSON; raw 196,609 poison rejected before JSON; unchanged existing 65,536 generic payload limits. Use finite table cases, not combinatorial fuzzing.

## Task 2 — Protected assembly lifetime and decoder completion

- [x] Add internal `AssetTransferReservationToken` with private/fileprivate minting, reservation, governor lifetime UUID and fresh secret. Add `ResourceGovernor.admitAssetTransfer(bytes:owner:) async throws -> AssetTransferReservationToken` and `completeAssetTransfer(_:owner:) async throws` (actor callers await; declarations need no redundant async). Reuse protected-secret storage if practical, but ensure token types cannot cross-release raster/decode lifetimes. Wrong owner/governor rejects; exact stale completion is idempotent. Generic release/releaseAll cannot refund it; state/disk resize cannot mutate it.
- [x] Charge using `.temporaryMemory`, not `.asset`. Quote whole declared compressed allocation plus a conservative second declared-size overlap allowance plus 4,096 control bytes before allocation: `2 * totalBytes + 4_096` admittedMemoryBytes, plus ResourcePolicy's existing 1,024 retainedState reservation charge. Fixed primitive binding contains only UUID-sized values, RuntimeIncarnation and existing bounded PublicationID; no arbitrarily retained provider string. Two input allowances cover controlled Data COW/finish snapshot overlap; do not grow the buffer or retain prior chunk frames. This is host-controlled accounting, not a Foundation allocator RSS guarantee.
- [x] Internal `AssetTransferBinding: Equatable, Sendable` fields: `incarnation: RuntimeIncarnation`, `connectionToken: UUID`, `publicationID: PublicationID`, `assignmentToken: UUID`. The latter is a host-minted canonical assignment/scope nonce, never provider input. It represents a current verified publisher/digest/feature/privacy assignment; the later runtime integration must derive/revalidate that authority, which this primitive cannot prove alone.
- [x] Internal `BoundedAssetTransferAssembler` is a final lock-gated class, initialized for one immutable incarnation, with the trusted RuntimeClock and existing AssetImageDecoding instance. Derive the governor from decoder/coordinator or require exact actor identity, so assembly and decode cannot silently use different governors. Shared decoder remains shared across assemblers; no decoder per transfer. Methods: `begin(totalBytes:binding:) async throws -> UUID`; `append(transferID:binding:offset:bytes:) async throws -> Int`; `finish(transferID:binding:) async throws -> AssetRasterBacking`; `abort(transferID:binding:) async throws`; `expire() async throws`; `close() async throws`. Cleanup failures must propagate; never silently discard a governor completion failure. Expose readonly `nextDeadline: Duration?` for the eventual existing deadline service, never a timer.
- [x] Slot states must distinguish idle/admitting/receiving/decoding/disposing/closed, with exact operation nonce through governor awaits. Set a constant-sized admission gate before the first await; deny concurrent begin immediately, without queueing or keeping its Data. Validate binding/length/clock before requesting money. Allocate the full fixed-count Data only after token admission and a postawait authority/close check; use in-place writes, no append growth or chunk cache. Return begin's fresh host UUID only after admission/allocation succeeds. Denial before admission does not allocate assembly or grant credit.
- [x] Use a nonrenewable 30-second trusted monotonic deadline from begin acceptance; validate finite wall time and nonnegative monotonic time, consistent with existing host guards. For safe deadline addition require monotonic <= Duration.seconds(Int64.max - 31); this is arithmetic protection, not a new ten-year uptime policy. Retain the last valid monotonic sample and reject backward samples without extending a deadline. Every append/finish checks current clock; deadline equality expires. Chunks do not extend it. `expire` services idle receipt waiting; close/disconnect integration will invoke close. Deadlines beyond native synchronous codec completion cannot interrupt ImageIO; expiry invalidates return authority while retaining live decode charges.
- [x] Append checks exact token, immutable binding, offset==received, and `bytes.count == min(65_536, totalBytes-received)`. Require exactly ceil(total/65_536) chunks; reject empty, short intermediate, duplicate, overlap, gaps, excess and postcomplete chunk. A foreign/stale token or binding must not mutate/release the current transfer. An exact transfer with invalid progression is terminal: async append gates the slot through explicit disposal and governor completion before returning its failure. No hidden cleanup Tasks.
- [x] Finish requires received==total, marks decoding before its first await, and passes bytes only inside a private lexical helper to decoder.decode. Do not return Data or expose a generic closure that could retain it. Finish holds the assembly token until the helper's Data/CFData references have ended and stored buffer is cleared, then completes token. Keep slot unavailable through refund and recheck operation/close/expiry after every await before returning protected raster. Cancellation, decoder error, abort, expiry and close use the same exact cleanup owner; abort/close during native decode only revoke return authority until decode actually ends. Never refund early or allow a newer transfer to be cleared by an older completion.
- [x] A completed protected raster is a safe primitive lifetime boundary: dropping compressed Data can refund only compressed assembly. Existing decoder independently prepays 10,162,688 temporary bytes and final raster disposal remains protected. Returned backing still grants no publication alias or permission; canonical import commit is outside this slice.

## Root preflight clarifications — binding implementation contract

- `admitAssetTransfer(bytes:owner:)` takes the declared compressed byte count (1...1,048,576), NOT a precomputed charge. It computes `2 * bytes + 4_096` only after validation. The existing 1,024 entry charge stays separate; expected admitted memory is exactly the computed quote and assetBytes stays zero. Use an opaque distinct token with fileprivate minting and the existing protected entry secret/lifetime pattern, without expanding every unrelated governor entry. No extra allocation pool, disk namespace or new policy ceiling.
- Exact assembler initializer: `init(incarnation: RuntimeIncarnation, clock: any RuntimeClock, decoder: any AssetImageDecoding)`. Governor derives from `decoder.assetGovernor`; no separately configurable accounting domain. AssetTransferBinding is module internal with immutable fields from the plan. The instance accepts only binding.incarnation == its own; owner comes from binding.publicationID.addonID. All host binding arguments must be canonically derived by the eventual caller; this primitive grants no authentication.
- Append/finish/abort first match token and full binding, then check time/progression. Foreign or stale authority returns sessionRevoked without changing or disposing the current transfer. Busy admission returns resourceDenied. Invalid lengths/shape/progression/incomplete finish return invalidPayload. An incomplete finish of the exact current transfer is terminal and cleans up; stale finish preserves a replacement. Expiration returns deadlineExceeded on request paths; explicit expire cleans up silently on success. Invalid/backward trusted clock samples return invalidPayload and revoke an exact active transfer without extending its deadline. Noncancelled normal decoder errors become a bounded AddonFailure code; avoid retaining an arbitrary Error across assembly refund. Task cancellation propagates CancellationError after cleanup.
- The first valid time is sampled before admission and the acceptance sample is checked again after reservation; the 30-second deadline begins at accepted begin, never renews, and is checked through final decoded return. Pending begin is already exclusive across the governor hop; close during admission prevents allocation/UUID grant and releases any later admitted token.
- The final decode helper alone may borrow compressed Data. Outer finish control and the pending refund record carry scalar token/nonce/binding plus an optional protected raster, never a compressed buffer or generic closure result. Clear the stored buffer and let the helper frame exit before completing the assembly token. Known raster pixels remain independently charged if a close/expiry prevents returning them. Keep decoding/disposing exclusive until the actual decoder completes and refund is done. Close/abort/expire during decoding mark revocation but do not own that cleanup, start a cleanup task or free the slot. The host must explicitly close an owned assembler; do not invent a Task-in-deinit cleanup path.
- Readonly `nextDeadline` is bounded scalar observation only, and may disappear on logical close even while decoding drains. Idle/closed expire and repeated close are idempotent; abort with no exact current transfer is stale authority. After ordinary finish/error/abort/expiry and completed disposal, a nonclosed instance accepts a fresh token; close never reopens it.
- All response optional-field shape rules are validated in constructors and decoding. For chunk acknowledgment nextOffset must equal request.offset + request.bytes.count when matching; abort and finish successful responses require the request's transferID. Failure has no token fields and matches UUID/operation. Imported response validates existing AssetHandle; publication authority is still a host integration concern. Begin PublicationID bounds: AddonID max255 ASCII bytes plus two36-byte UUIDs and fixed JSON overhead. Imported handle has two bounded AddonID occurrences, four UUIDs including response correlation/token, assetID max128 ASCII, bounded decimal dimensions/revision and fixed JSON overhead; calculate the actual field count conservatively and test real maximal constructors. Do not copy or reimplement the existing semantic validators. Nested existing Codable types retain their own field behavior; strict exact fields apply to the new request/response envelope, not a claim of recursive lexical duplicate detection.
