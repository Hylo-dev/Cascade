# Caffeinate widget options integration

The user requested a real Caffeinate trial of the existing shared widget options
container and the `ADDON-NOTCH-OPTIONS` TODO. This is a follow-up to the committed
widget fullscreen platform, starting at `1298bc4d149d7e8d8fef0a3d5e5a8493ef913bb0`.

## Accepted behavior

- The compact cup toggles Caffeinate independently. Its text/disclosure opens
  the shared notch options page; an icon-only widget has the same context action.
- The page provides the existing duration presets, keep-display-awake, Stop and
  acknowledgments. Native Back and the existing finite container transitions apply.
- Choosing duration while stopped saves the preset. Choosing a different duration
  while active starts that duration from selection. Indefinite has no deadline.
  Changing only display behavior preserves the current absolute deadline.
- The bundled plugin retains the common action broker, current revision, token,
  permissions and shared document budgets. A rendered eligible source creates the
  exact opening origin; delayed or dismissed requests cannot reopen the page.
- Source updates keep the live page current. Withdrawal, Back, display removal
  and termination release its authority. No detached menu/window or contextual
  page replacement implements this feature.
- Native assertions remain on the existing background owner, with one finite
  deadline timer and no idle polling. External managed-launcher qualification
  remains outside this builtin compatibility integration.

screen-capture permission cannot stand in for an actual successful UI scenario.
